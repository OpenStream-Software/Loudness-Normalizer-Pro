Loudness Normalizer Pro
Batch EBU R128 loudness normalization for MP3 files.

Loudness Normalizer Pro brings your whole music library to the same volume level, so you stop reaching for the volume knob between tracks. Pick a folder, analyze, and normalize in a few clicks. It's free, with no account needed.

Features

Broadcast-standard normalization. Two-pass EBU R128 loudness normalization powered by FFmpeg loudnorm, with a default target of -14 LUFS (adjustable in Settings).

Batch processing. Choose a source folder and process every MP3 in it in one run, with optional subfolder scanning.

Analyze first, or do it all at once. Run Analyze on its own to check your files, or use Analyze & Auto-Normalize to do both steps in one go.

High-quality output. Normalized MP3s are saved at up to 320 kbps (matching the source), and your originals are never overwritten.

Live progress. A queue shows each file's size and status, with an elapsed timer and an estimated time remaining while it works.

Resume interrupted runs. Closed the app or lost power mid-batch? Pick up where you left off.

Safe re-runs. Your Save Location is always skipped when scanning, so already-normalized files are never processed twice.

Recent Normalized list. Play a finished file or jump straight to its folder with one click.

Cancel any time. Stop a run whenever you need to.

Built-in guide. A searchable How to Use guide is just a click away.

Runs on your PC. FFmpeg is bundled, so there's nothing extra to install.

Truly free. No account needed. No paywalls. Unlimited use.
